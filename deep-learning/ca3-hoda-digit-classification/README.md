# CA3: Hoda Persian Digit Classification

This project trains multilayer perceptron models for Persian handwritten digit classification using the Hoda dataset.

## What I built

- Data loading from MATLAB `.mat` files.
- Preprocessing for handwritten digit images.
- MLP-based classification experiments.
- Optimizer and hyperparameter experiments, including Comet-based tracking notebooks.

## Reported results

- Base MLP experiment: about 99.22% training accuracy and 97.45% test accuracy.
- Tuned experiment: about 100.00% training accuracy and 98.05% test accuracy.
- Optimizer-search notes report best test accuracy around 98.45% to 98.55%, depending on the run.

Notebook outputs and Comet experiment links were removed from this GitHub-ready copy.
