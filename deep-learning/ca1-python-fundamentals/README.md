# CA1: Python Fundamentals

This assignment was a practical Python warm-up before the deeper machine learning coursework. It covers basic syntax, strings, lists, dictionaries, boolean logic, functions, control flow, and object-oriented programming exercises.

## Included work

- Part 1: Python basics, data structures, loops, conditions, FizzBuzz, and prime-number checks.
- Part 2: functions and small OOP tasks, including classes such as `Cylinder` and `Line`, plus exercises such as `blackjack`, `spy_game`, and `count_primes`.

## Why it matters

The assignment helped build the Python fluency needed for later neural-network and reinforcement-learning implementations, especially writing functions clearly, organizing small programs, and testing behavior with simple examples.
