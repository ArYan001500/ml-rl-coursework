- `D:\Projects\ReinforcementLearningTR3` maps to Reinforcement Learning Project 3.
- `D:\Projects\RlProject` maps to Reinforcement Learning Project 4.

The folder `D:\Projects\DLCA4` does not match the submitted CA4 folder by file content. It is included separately as `deep-learning/ca4-advanced-experiments` because it contains related flower-classification experiments but should not be presented as the exact final submission.

The GitHub-ready copy keeps implementation work and supporting lightweight artifacts, while excluding reports, prompts, large datasets, videos, archives, generated environments, and private/local execution traces.
