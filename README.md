# Machine Learning Coursework Portfolio

This private repository collects my Deep Learning and Reinforcement Learning coursework projects in a clean GitHub-ready structure.

The original submission folders contained reports, assignment prompts, videos, archives, local IDE files, virtual environments, generated checkpoints, and large datasets. This repository keeps the parts that are useful for code review and portfolio work: source code, cleaned notebooks, small datasets, selected training logs, selected plots, and lightweight model weights where they are needed to reproduce the demonstrations.

## Structure

- `deep-learning/ca1-python-fundamentals`: Python practice notebooks used as preparation for later machine learning work.
- `deep-learning/ca2-numpy-neural-network`: a from-scratch NumPy neural network for cardiovascular dataset classification.
- `deep-learning/ca3-hoda-digit-classification`: Persian digit classification on the Hoda dataset using MLP experiments and optimizer searches.
- `deep-learning/ca4-flower-classification`: CNN-based flower image classification with controlled optimizer comparisons and regularization.
- `deep-learning/ca4-advanced-experiments`: a separate working version with deeper CNN, transfer learning, and Keras Tuner experiments.
- `reinforcement-learning/project-1-dynamic-programming-and-bandits`: Gridworld dynamic programming and ten-armed bandit experiments.
- `reinforcement-learning/project-2-temporal-difference-and-planning`: n-step SARSA, Dyna-Q, and Dyna-Q+ experiments on Cliff Walking.
- `reinforcement-learning/project-3-mountain-car-function-approximation`: tile coding with semi-gradient SARSA for Mountain Car.
- `reinforcement-learning/project-4-deep-rl-control`: Double DQN for Mountain Car and PPO/SAC for Pendulum-v1.

## Notes

The notebooks were cleaned before publishing: execution outputs were removed, local-only metadata was reduced, and personal identifiers or online experiment links were redacted where they appeared in notebook content. The original project folders on disk were not modified.
